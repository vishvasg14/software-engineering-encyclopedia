# 01 — ES vs TS Basics

## What this demonstrates

The relationship between JavaScript (ES) and TypeScript: TS is a syntactic superset of JS; valid JS is valid TS.

## Files

- `basic.js` — plain JavaScript.
- `basic.ts` — TypeScript-typed version.

## Run

```bash
# JS
node basic.js

# TS — requires `tsc` or `tsx`
npx tsx basic.ts
# or: npx tsc basic.ts && node basic.js
```
