# Spring Ecosystem Books Reference

This file catalogs the authoritative books on Spring Framework, Spring Boot, Spring Data, and related technologies that the Spring Ecosystem document draws from.

## Foundational Spring books

- *Spring in Action* — Craig Walls (Manning). The most popular Spring introduction.
- *Spring Start Here* — Laurentiu Spilca (Manning). Accessible introduction.
- *Pro Spring 6* — Cosmin Vasiu, Iuliana Cosmina, Rob Harrop, Chris Schaefer (Apress). Comprehensive reference.
- *Spring 6 Recipes* — Marten Deinum, Daniel Rubio, Josh Long (Apress). Cookbook style.
- *Spring 6 Design Patterns* — Joseph B. Ottinger, Hardy Prasad (GitHub repo).

## Spring Boot books

- *Spring Boot in Action* — Craig Walls (Manning).
- *Spring Boot: Up and Running* — Mark Heckler (O'Reilly). Concise introduction.
- *Learning Spring Boot 3* — Greg L. Turnquist (O'Reilly). Comprehensive.
- *Spring Boot 3.0 Cookbook* — Felip Miguel Puig (Packt).
- *Pro Spring Boot 3* — Felipe Gutierrez (Apress).
- *Cloud Native Spring in Action* — Thomas Vitale (Manning). Spring Boot for cloud.

## Spring Data books

- *Spring Data JPA - Reference Documentation* — Oliver Gierke (free online).
- *Pro Spring Data* — Mark Pollack, Oliver Gierke, Thomas Risberg, Jon Brisbin, Michael Hunger (Apress).
- *Spring Data* — Pär Krüger (Packt).

## Spring Security books

- *Spring Security in Action* — Laurentiu Spilca (Manning). Excellent practical guide.
- *Spring Security 6 Recipes* — Maken Nosrati, Massimo Nardone (Apress).
- *Pro Spring Security* — Carlo Scarioni (Apress).
- *OAuth 2 in Action* — Justin Richer, Antonio Sanso (Manning).

## Spring Cloud books

- *Spring Cloud in Action* — Carnell, Sanchez.
- *Spring Microservices in Action* — John Carnell (Manning).
- *Cloud Native Spring in Action* — Thomas Vitale (Manning).

## Spring Batch books

- *Spring Batch in Action* — Arnaud Cogoluegnes, Thierry Templier, Gary Gregory, Olivier Bazoud (Manning).
- *Pro Spring Batch* — Michael Minella, Lucas Ward, Michael Hunger (Apress).

## Spring WebFlux / Reactive books

- *Spring in Action: Reactive Spring* — various.
- *Reactive Spring* — Josh Long (various presentations).

## Hibernate books

- *Java Persistence with Hibernate* — Christian Bauer, Gavin King, Gary Gregory (Manning).
- *Hibernate Tips* — Thorben Janssen (Createspace).
- *High-Performance Java Persistence* — Vlad Mihalcea (Leanpub, frequently updated).
- *Hibernate Search in Action* — Emmanuel Bernard, John Griffin, Sanne Grinovero (Manning).

## Java books (background)

- *Effective Java* — Joshua Bloch (Addison-Wesley).
- *Java Concurrency in Practice* — Brian Goetz et al. (Addison-Wesley).
- *Clean Code* — Robert C. Martin (Prentice Hall).
- *Designing Data-Intensive Applications* — Martin Kleppmann (O'Reilly).
- *Head First Design Patterns* — Eric Freeman et al. (O'Reilly).

## Testing

- *Effective Unit Testing* — Lasse Koskela (Manning).
- *Testing Microservices with Mountebank* — Brandon Byars (Manning).
- *xUnit Test Patterns* — Gerard Meszaros (Addison-Wesley).
