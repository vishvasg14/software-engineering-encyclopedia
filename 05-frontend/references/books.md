# Frontend Books Reference

This file catalogs the authoritative books on Angular, RxJS, React, Vue, and Svelte that the Frontend document draws from.

## Angular books

- *ng-book — The Complete Book on Angular* — Nate Murray, Felipe Coury, Ari Lerner, Carlos Taborda (Fullstack.io).
- *Angular in Action* — Jeremy Wilken (Manning).
- *Pro Angular 16* — Adam Freeman (Apress).
- *Angular — The Complete Guide* — Maximilian Schwarzmüller (Udemy).
- *Effective Angular* — Roberto Heckers (Leanpub).
- *Learning Angular* — Brad Dayley, Brendan Dayley, Alex Dayley (O'Reilly).
- *Programming Angular* — Christoffer Noring (O'Reilly).
- *Angular for Enterprise-Ready Web Applications* — Doguhan Uluca (Apress).

## RxJS books

- *RxJS in Action* — Paul P. Daniels, Luis Atencio (Manning).
- *Reactive Programming with RxJS 7* — Sergi Mansilla (Leanpub).
- *Mastering Reactive JavaScript* — Erich de Souza (Packt).
- *Reactive Programming with RxJS* — Frederik Bieberstein (Packt).

## React books

- *Learning React* — Alex Banks, Eve Porcello (O'Reilly).
- *React in Action* — Mark Tielens Thomas (Manning).
- *Pro React 16* — Adam Freeman (Apress).
- *React — The Complete Guide* — Maximilian Schwarzmüller (Udemy).
- *You Don't Know JS: ES6 & Beyond* — Kyle Simpson (O'Reilly).

## Vue books

- *Vue.js: The Complete Guide* — Maximilian Schwarzmüller (Udemy).
- *Vue.js in Action* — Erik Hanchett, Benjamin Listwon (Manning).
- *Pro Vue.js 3* — Adam Freeman (Apress).
- *The Majesty of Vue.js 2* — Alex Kyriakidis, Kostas Maniatis, Evan You.

## Svelte books

- *Svelte and Sapper in Action* — Mark Volkmann (Manning).
- *Svelte — The Complete Guide* — Maximilian Schwarzmüller (Udemy).

## JavaScript and TypeScript (background)

- *JavaScript: The Definitive Guide* — David Flanagan (O'Reilly).
- *You Don't Know JS* (series) — Kyle Simpson (O'Reilly). Free online.
- *Effective TypeScript* — Dan Vanderkam (O'Reilly).
- *Programming TypeScript* — Boris Cherny (O'Reilly).
- *Designing Data-Intensive Applications* — Martin Kleppmann (O'Reilly).

## CSS and HTML

- *CSS Secrets* — Lea Verou (O'Reilly).
- *CSS: The Definitive Guide* — Eric Meyer, Estelle Weyl (O'Reilly).
- *HTML5: The Living Standard* — Anne van Kesteren (online reference).

## Web performance

- *High Performance Browser Networking* — Ilya Grigorik (O'Reilly). Free online.
- *Web Performance in Practice* — Alessandro Cauduro (Leanpub).
- *Designing for Performance* — Lara Callender Hogan (O'Reilly).

## Testing

- *Effective Unit Testing* — Lasse Koskela (Manning).
- *Testing Vue.js Applications* — Edd Yerburgh (Manning).
- *Testing Angular Applications* — Jesse Palmer, Corinna Cohn, Mike Giambattista (Manning).
