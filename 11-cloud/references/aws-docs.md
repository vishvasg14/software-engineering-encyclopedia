## Regions and AZs

- **Regions:** isolated geographic areas. ~30 globally.
- **Availability Zones (AZs):** 2-6 per region. Independent data centers.
- **Local Zones:** mini-regions for low-latency (e.g., Las Vegas).
- **Wavelength:** 5G + AWS.

## Pricing models

- **On-Demand:** pay per use; flexible.
- **Reserved:** 1- or 3-year commit; up to 75% discount.
- **Savings Plans:** flexible commit; up to 72% discount.
- **Spot:** up to 90% discount; can be reclaimed.
- **Dedicated Hosts:** full host for compliance.

## Free tier

- 12-month free tier for new accounts.
- Always-free services (e.g., Lambda 1M requests/month).
- Trials (e.g., RDS, SageMaker).

- **AWS CLI:** <https://aws.amazon.com/cli/
